# 🎯 AI Course Recommendation System

## 📌 Project Overview

This project recommends courses to users based on their interests using a Content-Based Recommendation System.

The recommendation engine converts course descriptions into numerical vectors using TF-IDF and compares them with user interests using Cosine Similarity.

---

## 🚀 Features

- Course Recommendation System
- Content-Based Filtering
- TF-IDF Vectorization
- Cosine Similarity
- User Interest Matching

---

## 🛠 Technologies Used

- Python
- Pandas
- Scikit-learn

---

## 📂 Dataset

The dataset contains:

- Course Name
- Skills

Example:

| Course | Skills |
|---------|---------|
| Machine Learning | machine learning python data science |
| Web Development | html css javascript |

---

## ⚙️ Workflow

1. Load Dataset
2. Convert Skills into TF-IDF vectors
3. Take User Input
4. Calculate Cosine Similarity
5. Recommend Top Courses
